# Validation

Every number in this file is written by `shadowcast validate` and committed. Nothing here is
typed in by hand, and nothing is quoted in the README or the write-up that does not appear here
first.

The reason for that rule: this project's whole claim to being more than a visualisation is that
it has a ground-truth oracle and submits to it. A figure that cannot be regenerated by a command
is a figure someone will eventually be unable to defend.

> Nothing measured yet. The engine is at M0 (grid and bitset primitives). Sections below are the
> committed shape of the report, so it is obvious what is missing.

diffusion, then negative information is contributing nothing and the central claim is empty.
